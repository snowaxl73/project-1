# 청약서 보완 점검

수기 서면청약 청약서 스캔본을 **하나생명 작성 샘플** 기준으로 증번별로 점검하고,
하나로시스템(ga.hanalife.co.kr)에 붙여넣을 보완요청 문구를 만드는 웹 도구입니다.

## 기능
- **증번별 점검**: 증번을 등록하고 페이지(UW01, UW02, UW03, UW05, 상품설명서, UW13~UW22, UW24, UW45, UW50, HN01)의 필수 작성란마다 정상 / 미작성 / 오류 / 수정필요 / 해당없음을 표시합니다.
  - 성명·서명처럼 개인별 내용은 **작성 여부만** 확인합니다.
  - 미성년자 친권자, 지정대리청구인, 타사 승환 같은 항목은 **해당 시**에만 점검합니다.
- **보완요청 문구 자동 생성**: `UW01_회사명란_회사명작성`, `UW03_운전란_가필 따라쓰기란 작성` 형식으로 만들어 주며, 복사해서 하나로시스템의 해당 증번에 붙여넣으면 됩니다.
- **보완 완료 안내**: 모든 항목이 정상이거나 해당없음이면 보완 완료 안내 문구가 나옵니다.
- **작성 샘플 비교**: 페이지별 샘플 이미지와 스캔본을 나란히 볼 수 있습니다. 이미지는 브라우저 안에서만 쓰이고 서버로 올라가지 않습니다.
- **템플릿 편집**: 필수 작성란과 기본 문구를 고칠 수 있고, JSON으로 내보내거나 가져올 수 있습니다.
- **전체 목록**: 모든 증번의 보완요청을 한 번에 복사하거나 CSV(엑셀)로 내려받을 수 있습니다.

점검 결과와 템플릿은 브라우저(localStorage)에 저장됩니다. 스캔 이미지는 개인정보 보호를 위해 저장하지 않습니다.

## Vercel 배포
빌드 단계가 없는 정적 사이트입니다(`public/` 폴더, `vercel.json`).

1. https://vercel.com/new 에서 GitHub 저장소 `snowaxl73/project-1`을 Import 합니다.
2. Framework Preset은 **Other**로 두고 그대로 **Deploy**를 누릅니다. (`vercel.json`에 출력 폴더 `public`이 지정되어 있습니다.)
3. 배포할 브랜치를 Production Branch로 지정하거나, 해당 브랜치를 main에 병합합니다.

CLI를 쓸 경우: `npx vercel --prod`

## 로컬 실행
```
npx serve public
```
